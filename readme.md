# THRESHOLD

First-person liminal horror shooter in Three.js — Kane Pixel–inspired backrooms worlds mixed with Doom-style combat.

## Levels

1. **Yellow Zone** — classic mono-yellow fluorescent backrooms
2. **Aisle Zero** — endless Costco / big-box retail liminal space
3. **Soft Lobby** — empty hotel corridors and atriums

## Controls

- WASD — move
- Mouse — look
- Click / LMB — shoot
- R — reload
- Shift — sprint
- 1 / 2 / 3 — switch levels
- Esc — release pointer

## Dev

```bash
npm install
npm run dev
```
